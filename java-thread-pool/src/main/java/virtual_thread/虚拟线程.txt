Virtual threads are lightweight threads that dramatically reduce the effort of

虚拟线程是Thread一种实例，且同样依赖于OS Thread操作系统线程来运行
虚拟线程是Thread在运行时不会在整个生命周期都占用OS Thread
- 多个虚拟线程可以在同一个操作系统线程上运行其Java代码，有效地共享OS线程
- 虚拟线程的数量可以远超操作系统线程的数量
