进程 Process: 应用启动后开启的进程，分配进程ID
线程 Thread: CPU调度的最小单位, 也叫轻量级进程LWP(Light Weight Process)

PID: Process ID 进程ID
TID: Thread ID  线程ID
NID: Native ID  操作系统层面的线程ID

"Thread-1" #12 prio=5 os_prio=0 tid=0x00007f8a6800a800 nid=0x5166
